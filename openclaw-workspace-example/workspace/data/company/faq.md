# 常见问题

## 产品与能力

| 问题 | 答案 |
|---|---|
| 云华数智主要解决什么问题？ | 帮助企业整合业务系统、治理 API、建设智能客服知识库，并提升客户咨询和技术支持效率。 |
| 是否支持私有化部署？ | 支持。Enterprise 套餐可选择私有化部署或混合部署。 |
| 是否能接入已有客服系统？ | 可以。常见方式包括 API 对接、工单同步、知识库导入和坐席辅助插件。 |
| 是否可以只做知识库，不做系统集成？ | 可以。Starter 套餐适合单业务域知识库试点。 |
| 是否支持多语言客服？ | 支持中文和英文知识库，其他语言需根据项目范围评估。 |

## 商务与交付

| 问题 | 答案 |
|---|---|
| 试点周期多久？ | Starter 和 Growth 套餐支持 30 天试点。 |
| 标准上线周期多久？ | 通常 6-10 周，取决于系统数量、数据准备和客户侧联调效率。 |
| 是否提供培训？ | 提供管理员培训、客服培训和运维交接培训。 |
| 是否能开增值税专用发票？ | 支持。 |
| 价格是否可以定制？ | Enterprise 套餐可根据部署方式、坐席数量、系统集成数量和服务等级定制。 |

## 安全与边界

| 问题 | 答案 |
|---|---|
| 是否需要客户提供真实密钥？ | 不建议在咨询阶段提供真实密钥。联调阶段应通过客户安全流程配置。 |
| 是否可以使用脱敏数据测试？ | 可以，推荐使用脱敏订单、会员、客服和接口样例进行测试。 |
| 是否会向外部用户暴露内部系统资料？ | 客服回答应只围绕业务资料、产品资料和客户提供的公开或脱敏信息。 |
