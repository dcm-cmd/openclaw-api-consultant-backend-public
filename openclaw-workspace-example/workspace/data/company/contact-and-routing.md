## 线索分配规则

| 客户问题 | 分配团队 | 响应建议 |
|---|---|---|
| 询问产品能力、套餐价格、试点 | 商务顾问 | 收集客户行业、规模、业务痛点和预计上线时间。 |
| 询问 API 治理、系统集成 | 解决方案顾问 | 收集系统数量、接口数量、数据域和当前问题。 |
| 询问私有化部署、安全合规 | 交付架构师 | 收集部署环境、网络隔离、权限和合规要求。 |
| 已签约客户报障 | 客户成功经理 | 收集合同编号、环境、影响范围和问题现象。 |
| 发票、付款、合同条款 | 商务运营 | 收集公司抬头、税号、合同编号和付款节点。 |

## 客服建议追问

| 场景 | 建议追问 |
|---|---|
| 客户问价格 | 询问客户公司规模、预计坐席数、业务域数量、是否需要私有化部署。 |
| 客户问能否集成 | 询问现有系统名称、接口文档是否齐全、是否支持 API 或数据库同步。 |
| 客户问上线周期 | 询问业务域数量、系统数量、数据准备情况和是否需要客户侧开发。 |
| 客户问安全 | 询问部署方式、权限模型、数据脱敏和审计要求。 |
