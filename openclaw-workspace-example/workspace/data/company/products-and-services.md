# 产品与服务

## 产品矩阵

| 产品名称 | 面向对象 | 主要能力 |
|---|---|---|
| 云华 API Hub | 企业 IT、研发平台团队 | API 目录、接口规范、鉴权、限流、幂等、错误码治理。 |
| 云华 Connect | 业务系统集成团队 | 订单、会员、售后、客服、财务等系统连接和数据同步。 |
| 云华 ServiceBrain | 客服与运营团队 | 企业知识库、智能问答、人工客服辅助、客户问题归因。 |
| 云华 Insight | 运营管理团队 | 业务指标看板、接口调用分析、售后问题统计。 |

## 典型服务

| 服务 | 交付内容 | 适用阶段 |
|---|---|---|
| 业务系统集成咨询 | 梳理系统边界、数据流、接口清单和改造优先级。 | 售前评估、项目启动 |
| API 规范设计 | 设计接口命名、请求响应结构、错误码、分页、鉴权、幂等规则。 | 方案设计 |
| 知识库建设 | 整理公司资料、产品资料、FAQ、案例和服务流程。 | 客服上线前 |
| 私有化部署实施 | 部署应用、配置权限、接入数据、联调验收。 | 项目交付 |
| 运维与优化 | 接口监控、知识库迭代、客服命中率优化。 | 上线后 |

## 推荐场景

| 场景 | 推荐方案 |
|---|---|
| 客户经常问产品能力和价格 | 云华 ServiceBrain + 企业资料知识库。 |
| 多个系统之间数据不一致 | 云华 Connect + 业务系统集成咨询。 |
| 开放 API 缺少统一规范 | 云华 API Hub + API 规范设计。 |
| 售后问题难以归因 | 云华 Insight + 客服工单数据分析。 |
